# atlarix-slack-demo

A tiny project for trying [Atlarix for Slack](https://atlarix.dev/slack): mention @Atlarix (or DM it) with a task, and it does the work in this repository's GitHub Actions and comes back with a pull request you approve from the thread.

`npm test` runs the tests. One of them fails on purpose.

Try, for example:

- `atlarix-agent/atlarix-slack-demo: fix the failing test`
- `atlarix-agent/atlarix-slack-demo: add a function that returns the number of items in a cart, with a test`
